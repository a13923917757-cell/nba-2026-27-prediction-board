# NBA 2026-27 排名预测积分榜

张颖 vs 陈锵 对 NBA 2026-27 赛季东西部 30 队排名的预测对照看板，实时更新、自动算分。

## 在线访问

GitHub Pages：https://a13923917757-cell.github.io/nba-2026-27-prediction-board/

## 功能

- **总分对比**：每队预测名次与实际名次的绝对差即失分，差 1 名扣 1 分，累计失分越低越好
- **逐队对照**：东西部切换，显示实际种子排名、两人预测名次与失分
- **最大失分**：双方单队失分 Top 6 条形图
- **偏离归因**：8 支关键球队为什么超出/低于预测（伤病、重建红利、换核心、卫冕后遗症等）
- **最近比赛日比分条**

## 数据与更新

- 数据源：ESPN 公开接口（`cdn.espn.com/core/nba/standings`、`core/nba/scoreboard`），浏览器端直接拉取，无后端、无密钥
- 打开页面即拉最新，页面每 5 分钟自动刷新
- 接口不可用时自动回退到内置快照（2026-11-20），并标注「快照模式」
- 排名口径为官方种子排名，同战绩按交锋/分区等细则决胜

## 部署

纯静态单文件，直接把 `index.html` 托管到任意静态服务即可（GitHub Pages / Vercel / Netlify / Nginx）。无需构建、无环境变量。

本地预览：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

注意：直接双击用 `file://` 打开时，浏览器会拦截跨域请求，页面会使用内置快照；用 http(s) 访问才能拉到实时数据。
